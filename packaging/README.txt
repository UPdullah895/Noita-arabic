Noita - تعريب كامل للعبة
Noita - Arabic translation
================================================================

ما هذا / What this is
----------------------------------------------------------------
تعريب كامل للعبة Noita عبر نظام الترجمة الرسمي في اللعبة. لا
يُعدَّل أي ملف من ملفات اللعبة: حذف مجلد mods/translation_ar
يعيد اللعبة كما كانت تمامًا.

A complete Arabic translation of Noita, using the game's own
translation-mod system. No game file is modified - deleting
mods/translation_ar puts the game back exactly as it was.


التركيب على ويندوز / Installing on Windows
----------------------------------------------------------------
انقر نقرًا مزدوجًا على install-windows.bat
سيبحث المثبّت عن اللعبة وحده. إن لم يجدها اضغط "استعراض..."
وحدّد المجلد الذي يحتوي على noita.exe

Double-click install-windows.bat
It finds the game by itself. If it cannot, click Browse and pick
the folder that has noita.exe in it.

إن ظهرت رسالة عن الصلاحيات، شغّل الملف بزر الفأرة الأيمن ثم
"تشغيل كمسؤول".
If it reports a permissions problem, right-click the file and
choose Run as administrator.


التركيب على لينكس / Installing on Linux
----------------------------------------------------------------
    ./install.sh

ولتحديد مسار اللعبة يدويًا / to give the path yourself:

    ./install.sh /path/to/Noita


تشغيل التعريب / Turning it on
----------------------------------------------------------------
1. شغّل اللعبة، افتح Mods وفعّل "Arabic Translation".
2. أعد تشغيل اللعبة.
3. افتح Options ثم Language واختر "العربية".
4. اخرج من اللعبة عبر القائمة مرة واحدة، فاللعبة لا تحفظ اختيار
   اللغة إلا عند الخروج السليم.

1. Start the game, open Mods and enable "Arabic Translation".
2. Restart the game.
3. Open Options > Language and choose العربية.
4. Quit from the menu once: the game only saves the language
   choice on a clean exit.


الإزالة / Removing it
----------------------------------------------------------------
اختر English من الخيارات أولًا، ثم:
ويندوز: شغّل install-windows.bat واضغط "إزالة".
لينكس:  ./install.sh --uninstall

Switch the language back to English first, then:
Windows: run install-windows.bat and click إزالة (Uninstall).
Linux:   ./install.sh --uninstall
