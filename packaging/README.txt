Noita — التعريب العربي / Arabic translation
================================================================

ما هذا / What this is
----------------------------------------------------------------
تعريب كامل لـ Noita عبر نظام الترجمة الرسمي في اللعبة: القوائم
والخيارات والعصي والتعاويذ والمواهب والمواد والمخلوقات والمناطق.
لا يُعدَّل أي ملف من ملفات اللعبة: كل شيء داخل mods/translation_ar،
وحذفه يعيد اللعبة كما كانت تمامًا.

A complete Arabic translation of Noita, using the game's own
translation-mod system. No game file is modified - the mod lives in
mods/translation_ar and deleting it puts the game back as it was.


المتطلبات / Requirements
----------------------------------------------------------------
ويندوز 10 أو 11، أو أي توزيعة لينكس حديثة. لا يلزم تثبيت أي برنامج.
Windows 10/11 or any modern Linux. Nothing else to install.


التثبيت على ويندوز / Installing on Windows
----------------------------------------------------------------
1. أغلق اللعبة.
2. انقر نقرًا مزدوجًا على install-windows.bat.
3. اضغط "تثبيت". سيبحث المثبّت عن اللعبة وحده؛ إن لم يجدها اضغط
   "استعراض..." وحدّد المجلد الذي يحتوي على noita.exe.
وإن ظهرت رسالة عن الصلاحيات، شغّل الملف بزر الفأرة الأيمن ثم
"تشغيل كمسؤول".

1. Close the game.
2. Double-click install-windows.bat.
3. Press Install. It finds the game by itself; if it cannot, press
   Browse and pick the folder that has noita.exe in it.
If it reports a permissions problem, right-click the file and
choose Run as administrator.


التثبيت على لينكس / Installing on Linux
----------------------------------------------------------------
    ./install.sh

ولتحديد مسار اللعبة يدويًا / to give the path yourself:

    ./install.sh /path/to/Noita

وإن ظهرت Permission denied، فمدير الملفات لم يحفظ صلاحية التنفيذ:
    chmod +x install.sh && ./install.sh


تشغيل التعريب / Turning it on
----------------------------------------------------------------
1. شغّل اللعبة، افتح Mods وفعّل "Arabic Translation".
2. أعد تشغيل اللعبة.
3. افتح Options ثم Language واختر "العربية".
4. اخرج من اللعبة عبر القائمة مرة واحدة، فاللعبة لا تحفظ اختيار
   اللغة إلا عند الخروج السليم.

1. Start the game, open Mods and enable "Arabic Translation".
2. Restart the game.
3. Open Options > Language and choose العربية.
4. Quit from the menu once: the game only saves the language
   choice on a clean exit.


الإزالة / Removing it
----------------------------------------------------------------
اختر English من الخيارات أولًا، ثم:
ويندوز: شغّل install-windows.bat واضغط "إزالة".
لينكس:  ./install.sh --uninstall

Switch the language back to English first, then:
Windows: run install-windows.bat and click إزالة (Uninstall).
Linux:   ./install.sh --uninstall


النسخة المدعومة / Supported version
----------------------------------------------------------------
تعديل ترجمة يعمل مع نسخ اللعبة الحالية: المفاتيح الجديدة تظهر
بالإنجليزية حتى تُترجَم، والباقي يبقى عربيًا.

A translation mod that follows the game's own keys: new keys show in
English until translated, the rest stays Arabic.
