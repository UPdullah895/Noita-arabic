# Arabic glossary — Noita

One term, one translation. Check here before translating anything that recurs.

## Register and style

- Modern Standard Arabic, short and plain. Noita's UI is terse; match it.
- No harakat: the font cannot position them, so they are stripped at build time.
  Where a word is ambiguous without them, reword it.
- UI labels are nouns (`السرعة`), not imperatives. Buttons are imperatives (`تطبيق`).
- Put `\n` only at real paragraph breaks. The build wraps lines to the English width.
- Keep `$0`, `$1`, `[ENTER]` etc. exactly; move them wherever Arabic word order needs.
- Units after numbers: `$0 ث` (seconds), `$0°` (degrees).
- Western digits stay as they are; the game inserts them at runtime anyway.

## Names

Finnish proper names are transliterated, not translated, matching what the
official translations do: Hiisi = هيسي, Stendari = ستنداري, Kolmisilmä = كولميسيلما,
Kivi = كيفي, Lukki = لوكي, Mestari = ميستاري, Henkevä = هنكيفا, Lohkare = لوهكاره,
Valo = فالو, Pimeys = بيميس, Steve = ستيف.
Descriptive creature names are translated ("Fire mage" = ساحر النار).

## Alchemical materials

Noita's invented "-ium" liquids become مادة + the effect noun. The gas or cloud forms use
سحابة instead of مادة, and the unstable forms append غير مستقرة.
